# Tandoory Tales — Digital Menu

Mobile-friendly Hindi/English online menu for Tandoory Tales, Best Mega Mall, Rohini Sector 24, Delhi.

## Publishing with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**; click **Save**.
3. After publishing, website: https://poplu2525.github.io/tandoory-tales-menu/

## Updating prices
Edit the `menuData` section near the bottom of `index.html` and commit the changes. The public website address and QR code stay the same.

## Confirm before print
- Verify all prices against your board.
- Punjabi Chaap is only featured; the price has not been confirmed.
- ₹199 chaap offer is based on the owner's instruction and may change.
- WhatsApp order button uses +91 72100 80540; check whether this number accepts WhatsApp.
- Generate the QR code from the *live website URL*, then test before printing.
